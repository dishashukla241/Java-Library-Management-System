📚 LIBRARY MANAGEMENT SYSTEM
A simple java-based library management system using Swing GUI and MySQL for database integration 

->Features 🛠
Add new books to the library 
View all available books 
Stores data persistently using MySQL 
Clean and user-friendly GUI using Swing 

->Tech Stack 💻
Java (JDK 17+ recommended)
Swing (for GUI)
MySQL (Database)
MySQL Connector/J (.jar file required)
